# Генератор и решатель лабиринтов

## 📌 Описание проекта
Консольное приложение на Python для генерации лабиринтов различных размеров и поиска оптимального пути выхода из них с использованием алгоритмов обхода графов.

## 🛠 Технологии и реализация
* **Язык:** Python
* **Реализация:** Модульная архитектура, где алгоритмы генерации и поиска пути отделены от логики отображения и работы с файлами.
* **Что использовано:** Двумерные массивы, структуры данных (очереди, стеки), алгоритмы поиска путей (BFS / DFS / Дейкстра).
* **Изученные инструменты:**
  * Реализация классических алгоритмов на графах и сетках.
  * Работа с файловым вводом/выводом для сохранения и загрузки лабиринтов.
  * Написание качественных юнит-тестов (`pytest`).

## 🚀 Инструкция по запуску
1. Установите зависимости:
   ```bash
   poetry install
   ```
2. Запуск приложения:
   ```bash
   python -m src.main --help
   ```
3. Запуск тестов:
   ```bash
   pytest
   ```
