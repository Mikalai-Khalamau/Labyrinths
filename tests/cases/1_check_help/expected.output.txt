usage: main.py [-h] {generate,solve} ...

Программа для генерации и решения лабиринтов в командной строке

positional arguments:
  {generate,solve}  Две команды: Генерация и решение.Использование: python
                    main.py [Команда] аргумент=значение ...
    generate        Создает лабиринт. Нужно задать алгоритм(--algorithm),
                    ширину(--width) и высоту(--height), файл для
                    записи(--output)(если не задать - выведет в консоль)
    solve           Находит путь в лабиринте. Нужно задать файл с
                    лабиринтом(--file), алгоритм(--algorithm),
                    стартовую(--start) и конечную(--end) точки, выходной
                    файл(--output)(если не задать, то в консоль)

options:
  -h, --help        show this help message and exit
